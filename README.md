# memelottery-data
Auto-generated public data for https://memelottery.vercel.app (PAPER trading only; no wallets, pools, quotes or secrets).
Written by memebot/lottery/web/publish.py: branch `data` is force-updated to ONE orphan commit per push, so every file
belongs to the same build (see `generated_ts` / `generated_time` inside each JSON). History is intentionally not kept.
